# Supply Chain Project – Wine Distribution (Germany)

This project simulates a wine supply chain in Germany using Python.

## Features
- Geocodes German cities (wineries, wholesaler, retailer, customers)
- Creates a directed graph with NetworkX
- Generates random customer locations using Faker
- Displays an interactive delivery map using Folium
- Detects invalid locations (e.g. water/sea)

## Technologies Used
- Python
- Pandas
- NetworkX
- Folium
- Faker
- Geopy

## Output
The script saves an HTML file:
``liefernetz_karte_with_blue_sea.html``  
Open it in your browser to view the network.
